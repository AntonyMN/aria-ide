Local, Self-Hosted LLMs

Aria IDE puts autonomous AI directly on your laptop. No API tokens, no monthly fees, and zero code leaks. Powered by local Ollama models with live on-screen command execution, structure auditing, and human-in-the-loop controls.

📺

On-Screen Live Command Execution

Never wonder what an AI agent is running behind the scenes. Commands stream character-by-character on screen with real-time stdout/stderr and sequential dependency preservation.

📁

Workspace & Structure Auditing

After each command executes, Aria inspects directory snapshots. Project scaffolding commands (e.g. laravel new blog) automatically shift working directory into ./blog and advise on the next steps.

⏸️

Interrupt & Guide with LLM

Need to steer the AI mid-flight? Hit interrupt at any point. Aria cleanly pauses, receives your feedback, and revises its implementation plan using the local model before continuing.

💻

Hardware & VRAM Estimator

Automatically calculates model weights, KV cache, and runtime RAM requirements against your machine's physical memory, flagging unsafe loads before system freezes occur.

⚡

Built with Tauri v2 + React 19

Fast, memory-efficient native desktop shell powered by Tauri Rust and Vite, featuring Monaco Editor split diffs and a full xterm pseudoterminal.

🛡️

100% Private & Offline

Works fully offline using Ollama models (such as Granite 4.2 8B, Qwen 2.5 Coder 7B, or DeepSeek Coder). Your intellectual property never leaves your machine.
